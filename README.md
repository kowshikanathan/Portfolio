# Kowshika S — UX/UI Designer & Frontend Developer Portfolio

> Designing digital products where visual design meets usability. "Good design is invisible — great design feels effortless."

A modern, responsive, high-impact personal portfolio built with **React 19**, **Vite**, and **Vanilla CSS**. Features an interactive dark/light mode, a filterable creative arsenal, a streamlined process framework, a chronological milestone journey, and live project showcases.

---

## 🚀 Key Features

- **Floating Capsule Navigation:** Sticky pill navigation with active scroll-spy, theme toggle, and mobile drawer.
- **Hero Landmark:** Unclipped illustrated tech avatar with floating tool badges, social links, and CV download.
- **About Me:** Professional bio, role overview, and live experience statistics.
- **Creative Arsenal (Toolkit):** Interactive 3-column tool showcase filterable across `UI/UX Design`, `Frontend`, `Creative & Inspiration`, and `Architecture & Technical`.
- **From Idea to Interface (Process):** 4-step structured methodology framework (`Understand` → `Structure` → `Design` → `Build`).
- **Growth & Milestones (Journey):** Chronological timeline with glowing track markers, duration badges, and skill tags.
- **Project Showcase:** Highlights real-world work including link management, academic platforms, fee portals, and beauty application case studies.
- **Interactive Contact:** Direct enquiry form integrated with email dispatch.
- **Universal Theming:** Full support for both light and dark themes with persistent user state.

---

## 🛠️ Tech Stack

- **Framework:** React 19
- **Bundler & Dev Server:** Vite 8
- **Typography:** Google Font (Poppins)
- **Icons:** Lucide React & Handcrafted Vectors
- **Styling:** Custom CSS Design System with CSS Custom Properties

## 📦 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/kowshikanathan/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
